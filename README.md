# Mashruuca Maxamed

Kani waa kaydka (repository) mashruucayga GitHub. Waxaan halkan ku kaydin doonaa koodhkayga, qoraaladayda, iyo mashaariicdayda mustaqbalka.

## Ujeeddada (Goal)
- Inaan barto isticmaalka GitHub.
- Inaan si ammaan ah u kaydiyo koodhkayga.
- Inaan la wadaago asxaabta kale koodhka aan qoro.

## Sida loo isticmaalo (Usage)
Waxaad si xor ah u daawan kartaa faylasha ku jira kaydkan, ama aad kala soo degto (clone) kombuyuutarkaaga.
